API Devises

Cette API fournit les derniers taux de change de référence de la Banque centrale européenne utilisés par Simulateur.

Endpoint

GET https://simulateur.site/api/devises

Réponse

La réponse JSON contient la date d'observation de chaque devise, les taux avec EUR comme devise de référence et la source BCE.
