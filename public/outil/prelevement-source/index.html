FISCALITÉ

Calculateur de prélèvement à la source

Calculez le montant prélevé sur votre revenu à partir de votre taux PAS.

Saisissez vos données puis lancez le calcul.
Méthode et sources

Le montant est calculé comme revenu net imposable × taux PAS. Le taux doit être celui communiqué par l'administration fiscale ; le calculateur ne détermine pas le taux personnalisé officiel.

Comment fonctionne le prélèvement à la source ?

Le prélèvement est calculé en appliquant votre taux de prélèvement au revenu net imposable entrant dans le champ du PAS. Ce calculateur reproduit donc le calcul du prélèvement sur une paie lorsque le taux PAS est déjà connu.

Il ne prétend pas déterminer votre taux fiscal officiel : celui-ci est calculé par l'administration à partir de votre situation et de vos revenus. Depuis le 1er septembre 2025, le taux individualisé est le taux par défaut pour les couples mariés ou pacsés soumis à imposition commune, avec possibilité d'opter pour le taux foyer.

Sources officielles : impots.gouv.fr et BOFiP — calcul du taux PAS.
