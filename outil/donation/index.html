Méthode et sources

Pourquoi le lien de parenté est déterminant

Les droits de donation sont calculés après application d'un abattement qui dépend notamment du lien entre le donateur et le bénéficiaire. Les donations antérieures du même donateur peuvent aussi réduire l'abattement encore disponible.

Dans les situations courantes, l'abattement parent-enfant est de 100 000 €. D'autres liens de parenté disposent de montants différents et certaines exonérations peuvent se cumuler sous conditions.

Une estimation, pas un acte fiscal

Le calculateur ne reproduit pas toutes les règles patrimoniales : donations particulières, assurance-vie, démembrement, transmission d'entreprise ou situations familiales complexes peuvent modifier le calcul. Pour une donation importante, le notaire peut sécuriser le traitement fiscal et civil.
